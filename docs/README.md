# M6 USB DAC 面板

为**山灵 M6（21 版）** 定制的 USB DAC 状态面板：插上电脑自动全屏弹出，实时显示**采样率 / 位深 / 格式 / 码率 / 音量**，并可直接调节音量。

- 界面：横屏 640×360 设计（真机 1280×720 @ dpr2），深空黑 + 琥珀金配色
- 壳：Android 7.1.1 / API 25，零第三方依赖，APK 约 0.9 MB
- 数据：全部来自设备本身，无网络、无电脑端代理

---

## 1. 安装

### 1.1 拷贝 APK

```powershell
# 设备已插入电脑（MTP 模式）时
adb push dist\m6-usbdac-panel-debug.apk /sdcard/
# 或在 M6 的文件管理器里直接打开已拷贝的 APK
```

也可以直接安装：

```powershell
adb install -r dist\m6-usbdac-panel-debug.apk
```

> 需要 M6 处于**安卓模式**（非纯净模式），并允许「未知来源应用安装」。
> 纯「纯净模式」会屏蔽第三方后台服务，自动弹出会失效。

### 1.2 授予两项关键权限

| 权限 | 作用 | 开启方式 |
|---|---|---|
| **无障碍服务** | 读取山灵音乐播放页的采样率文本（**这是唯一可用的数据源**，见 [SOURCES.md](SOURCES.md)） | 设置 → 无障碍 → 「M6 DAC 面板 · 采样率读取」→ 开启 |
| **显示在其他应用上层**（SYSTEM_ALERT_WINDOW） | 面板用悬浮窗承载，才不会遮挡山灵界面导致读不到数据 | 设置 → 应用 → M6 USB DAC → 在其他应用上层显示 → 允许 |

用 adb 也可以一次授权：

```powershell
adb shell settings put secure enabled_accessibility_services com.dsh.usbdac/com.dsh.usbdac.DacA11yService
adb shell settings put secure accessibility_enabled 1
adb shell appops set com.dsh.usbdac SYSTEM_ALERT_WINDOW allow
```

### 1.3 先打开一次

安装后从桌面点一次图标：它会拉起常驻服务并显示面板，随后立即退出自身（不占用前台），以便后续插线自动弹出。

## 2. 使用

1. M6 用数据线接到电脑，进入 **USB DAC 模式**（快捷菜单里切换）
2. **电脑开始放歌后**面板自动弹出（判定依据：USB 已接入 + ALSA 有活动音频流），每 400 ms 刷新一次
3. 拖动音量环 / 点 ± 按钮调音量，**直接写入系统媒体音量**，回读校验，失败会回滚并提示
4. 关闭面板有三种方式：
   - 点面板右上角「退出」
   - 下拉通知栏 → 通知里的「关闭面板」
   - 兜底：`adb shell am force-stop com.dsh.usbdac`
5. 关闭后常驻服务继续等待下次 DAC 信号

> 注意：普通「插数据线 / disk 模式」**不会**弹面板——那种模式下 ALSA 没有音频流，
> 正好和 USB DAC 模式区分开。想手动看面板就点一下桌面图标。

### 界面含义

```
┌──────────────────────────────────────────┐
│ M6 · USB DAC              ● 已连接 / 退出 │
├──────────────────────────────────────────┤
│   96          ← 采样率（真实读自山灵界面） │
│   kHz                                     │
│  24 bit      WAV        4608              │  ← 位深 / 格式 / 码率
│                                    ╭───╮ │
│                                    │30 │ │  ← 音量（真实系统音量，可拖拽）
│                                    ╰───╯ │
│   test96 · Unknown Artist                 │  ← 曲目（有则显示）
│   来源 · 山灵界面                          │  ← 数据源角标
└──────────────────────────────────────────┘
```

数据源角标会明确显示当前数值来自哪里：`山灵界面` / `内核 ALSA` / `无数据源`。**不会用演示数据冒充实时值**；确实读不到时显示 `--`。

## 3. 排错

| 现象 | 原因 / 处理 |
|---|---|
| 面板能弹出但采样率一直 `--` | ① 无障碍服务未开启；② 山灵音乐没有在前台显示过播放页；③ 山灵界面被别的窗口完全遮挡 |
| 横幅提示「请开启无障碍服务」 | 按 1.2 开启无障碍 |
| 插线不自动弹出 | 面板被手动退出过、或 App 被「强制停止」。重新点一次图标即可恢复常驻 |
| 面板显示但读不到曲目 | 本地播放时山灵播放页不在前台，曲目信息缺失（采样率仍可读）。**USB DAC 模式下曲目信息客观不存在**：音频由电脑经 USB Audio Class 送入，规范里没有元数据通道。因此曲目行已从界面移除，底部只用数据源角标标明当前数值来源 |
| 悬浮窗不显示 | `SYSTEM_ALERT_WINDOW` 未授权 |

查看实时日志：

```powershell
adb logcat -s DacA11y DacPanel
```

正常时会看到：

```
D/DacA11y: service connected
D/DacA11y: format text = WAV 96kHz/24bit/4608Kbps
```

## 4. 已知限制（实测结论，不是猜测）

1. **M6 的 HiFi 播放完全旁路 Android 音频栈**：播放 96kHz 音频时，`/proc/asound/*/hw_params` 全部 `closed`、`audio_flinger` 全部 `standby`、`mMusicActiveMs=0`。所以内核和框架都拿不到采样率，只能读山灵界面文本。
2. 因此**面板必须用悬浮窗**而不是普通全屏 Activity：Activity 覆盖会让山灵 `onStop`、访问树变 `null`。
3. 采样率依赖山灵界面存在 `playing_title` 文本节点（实测该控件是原生 `TextView`，格式形如 `WAV 96kHz/24bit/4608Kbps`）。
4. 曲目信息与采样率同源，山灵未显示播放页时就只有 `--`。
5. 按需求**不包含**增益控制与播放/暂停/上下一曲。

## 5. 从源码构建

```powershell
$env:JAVA_HOME='D:\Android Studio\Android Studio\jbr'
cd android
.\gradlew.bat assembleDebug
# 产物：android\app\build\outputs\apk\debug\app-debug.apk
```

`android/app/build.gradle.kts` 里把 `web/` 直接作为 assets 源目录：

```kotlin
sourceSets { getByName("main") { assets.srcDirs("../../web") } }
```

所以改界面只需要改 `web/`，重新构建即可，无需复制两份代码。

本地预览界面（浏览器）：

```powershell
node tools/serve.mjs 4173
# 打开 http://127.0.0.1:4173/            → 连接态（演示数据）
#      http://127.0.0.1:4173/?nobanner=1 → 隐藏演示横幅
#      http://127.0.0.1:4173/?state=disconnected → 断开态
```

## 6. 界面动效与设计参考

面板动效只挂在两个事件上——**面板弹出**和**状态变化**——不挂在 400 ms 刷新循环上
（骁龙 430 上「一直在动」的东西会累积成掉帧与耗电）。全部动效都是失败安全的：
动画挂在附加的 class 上，class 不存在时界面完全正常。

| 动效 | 触发时机 |
|---|---|
| 入场序列：顶栏 → 采样率 → 三格参数 → 音量环 → 底部收尾（含一道金色扫描线） | 面板每次弹出，播一次，约 940 ms |
| 状态点同心圆呼吸扩散 | 已连接时常驻 |
| 音量区联动：转环时环变粗发亮 + 末端光点跟手 + 数字放大提亮 + `±` 键按方向亮起 | 拖动音量环时 |
| 点 `±` 时按钮闪金光，环同步增减 | 点按音量键时 |
| 音量环外圈虚线旋转 | 写入音量、等待回读校验时 |
| 参数卡边框闪一次金光 | 采样率 / 位深 / 格式 / 码率**真的变化**时（值不变不闪） |
| USB 图标浮动 + 描边流光 | 断开待机时 |

想改或想加动效，看这两份：

- [UI-RESEARCH.md](UI-RESEARCH.md)：MotionSites / React Bits / UIverse / Aceternity UI
  四个站点的适配评估、可移植清单、以及 Chromium 51 禁用特性清单
- `ui-lab/index.html`：候选动效实验室（12 个可交互效果 + 3 个布局方案，
  直接双击打开，不需要起服务器）
- `ui-lab/knob.html`：**当前主题的设计稿**（KNOB 风格：纯黑 + 橙红 + 竖向渐变条 + 旋钮，
  含状态序列 I–IV 与设计规范）

## 7. 视觉主题（KNOB）

面板按 KNOB 交互美学做了主题重设计，核心三条：

1. **纯黑底 + 单一强调色**：背景 `#050505`，控件底 `#101014`；全站只有一个橙红
   `#FF5A1F`，只出现在状态点、音量条、数据源角标三处。
2. **音量从圆环改成竖直条 + 旋钮**：轨道形状就是音量本身——填充高度 = 音量百分比，
   调音量时条跟着升降（对应参考图「条随倒计时缩短」）；旋钮是把手，也是当前值指针，
   转动角度 = 音量百分比（对应参考图「旋钮图标转动」）。
3. **大圆角与重量级数字**：卡片圆角 28，采样率 78px / 字重 600 / 负字距。

交互变化：音量改为**在竖直条上上下拖动**（原来拖圆环）；`±` 步进键已按需求移除，
音量卡固定在**左侧**，采样率与参数在右侧。长采样率（44.1 / 352.8 / 2822.4 这类）
会自动降一档字号，不会撑出卡片。

**旧的金色主题已完整备份**在 `docs/archive/gold-theme/`（index.html、css、volume.js）。
要回退，把备份文件复制回 `web/` 对应位置再 `assembleDebug` 即可。

状态色也收敛到单色系：已连接 = 橙、写入中 = 亮橙呼吸、写入失败 = 红。

**背景材质**：面板底层铺一张石材纹理（`web/assets/texture.webp`，960×540 WebP、约 100 KB），
以 `opacity: 0.30` 压在内容下方，让纹理只做「有材质」的暗示。
`prefers-reduced-transparency` 下卡片会压成实色。

**卡片**：深色半透明卡（`rgba(26,27,32,0.90)`），纹理在卡内隐约透出但低于内容对比度。
（毛玻璃方案试过又回退了，原因见 [UI-RESEARCH.md](UI-RESEARCH.md)。）

**SONY 字标**：左上角是图片字标（`web/assets/sony-logo.webp`，透明底白字，显示高 15px），
旁边不再有 `USB DAC` 字样。

**字体**：思源黑体优先（`"Noto Sans CJK SC", "Source Han Sans SC", "思源黑体"`），
Android 原生中文字体就是这一支（Source Han Sans 与 Noto Sans CJK 同一字体）。

**右上角状态胶囊已移除**：正常工作时右上角留空（状态由音量区与底部数据源角标表达），
只有「检测中 / 通信中断 / 异常」这类需要用户注意的状态才会出现。

**曲目行已移除**：DAC 模式下音频来自电脑、UAC 没有元数据通道；本地播放也只有山灵播放页在前台时
才读得到。与其长期占位显示「信息不可用」，不如把这块空间还给布局——底部只保留数据源角标，
它标明「当前数值来自哪里」，这条诚实标记必须留着。
