M6 · USB DAC / KNOB Style

KNOB 风格设计稿 — 纯黑 + 橙红 + 竖直渐变条 + 旋钮指针

参照那张 KNOB 交互设计图的语言，把面板横屏化到 640×360： 纯黑底不承载任何卡片边框，所有层级靠字重与留白；唯一的强调色是橙红； 音量从「圆环」改成 竖直渐变条 + 旋钮——条的形状就是音量本身（对应参考图 III→IV 的 「条随倒计时缩短」），旋钮是把手也是当前值指针（对应参考图 I→II 的旋钮图标转动）。
